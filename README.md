# 우리말 꽃밭 — 개인 사전 이미지 만들기

Firebase·로그인·서버 설정 없이 사용하는 초등 국어 웹앱입니다. 학생이 직접 고친 표현을 색깔 포스트잇으로 모아 사전 전체를 한 장의 PNG 이미지로 다운로드합니다. 실시간 공유 기능은 없습니다. 완성 이미지를 선생님이 사용하는 학급 게시판이나 제출 도구에 올려 함께 보세요.

## GitHub → Vercel 배포
1. ZIP 압축을 풀고 내부 파일을 GitHub 새 저장소의 루트에 올립니다.
2. Vercel → Add New Project → 해당 저장소 선택.
3. Framework: Other / Build Command: 비움 / Output Directory: `.` → Deploy.
4. 학생들에게 배포된 주소 하나를 공유합니다. 학생·교사 주소 구분이나 별도 참여 코드는 없습니다.
GitHub Pages에서도 저장소 루트의 index.html로 사용할 수 있습니다.

## 학생 사용 방법
1. 이름 또는 별명과 모둠을 입력합니다.
2. 낱말 버튼을 고르거나 직접 낱말을 입력합니다.
3. 바꾼 말, 바꾼 까닭, 사용 문장(선택)을 적고 ‘내 사전에 붙이기’를 누릅니다.
4. 여러 포스트잇을 모아 나만의 사전을 만듭니다. 수정·삭제와 마음에 드는 말 표시가 가능합니다.
5. ‘사전 이미지 다운로드’를 누르면 모든 포스트잇과 이름·모둠이 들어간 PNG 한 장을 저장합니다. 검색 조건과 관계없이 전체 사전이 저장됩니다.
6. 내려받은 이미지를 선생님께 제출하거나 학급 게시판에 올립니다.

## 저장과 이미지
이 브라우저의 localStorage에 자동 저장합니다. 다른 기기·다른 브라우저에는 옮겨지지 않습니다. 공용 기기에서는 이전 학생의 사전을 삭제하고 사용하세요. 시크릿 모드나 브라우저 데이터 삭제 시 사전이 사라질 수 있으므로 완성 이미지를 다운로드하세요.
이미지는 가로 1600픽셀, 내용에 맞춘 세로 길이로 생성되며 두 열의 포스트잇을 배치합니다. 한 사전에 최대 40개를 담습니다. 매우 긴 사전은 기기 메모리에 따라 이미지 생성이 실패할 수 있으므로 수업에서는 4~8개 정도가 적당합니다.
세종대왕·한글 책은 수업용 SVG 창작 삽화입니다. 책은 훈민정음 원본의 복제품이 아닙니다. 외래어와 신조어가 모두 틀린 말은 아니라는 안내를 포함합니다. 정답 자동 판정 대신 뜻과 상황을 살린 표현을 토의합니다.

## 수업 발문
- 뜻을 모르는 사람이 이 말을 들으면 어떨까요?
- 바꾼 표현이 원래 뜻을 잘 살렸나요?
- 바른말을 써야 하는 까닭을 우리 사전에서 찾아볼까요?

## 확인 범위
JavaScript 문법·HTML 요소 연결·SVG·배포 설정을 점검했습니다. 실제 갤럭시탭에서 이미지 다운로드와 글꼴 표시를 수업 전에 한 번 확인하세요. 별도 Firebase 설정은 필요 없습니다.

## 낱말 예시
신조어·외국어·외래어·줄임말을 각각 12개씩, 총 48개 제공합니다. 추가로 거친 말 4개도 포함합니다. 낱말을 누르면 원래 말과 종류가 자동 입력되고 뜻이 표시됩니다. 바꾼 말은 학생이 직접 생각해 입력합니다. 신조어와 줄임말은 겹칠 수 있으며, 외래어는 틀린 말이라는 뜻이 아닙니다. 제시된 뜻은 수업 상황에서 사용하는 뜻으로, 문맥에 따라 다른 뜻이 있을 수 있습니다.

## 추가 자료 반영
첨부된 ‘우리말 바르게 놀이’ 자료를 참고해 댕댕이·혼밥·열공·노답·체크·디저트·스포·스킵·멘붕 등을 추가했습니다. 총 21개 낱말에서 문장 속 쓰임을 볼 수 있습니다. 자료의 정답 문장을 자동 입력하지 않고 학생이 스스로 바꾸도록 구성합니다. 노답처럼 여러 언어를 결합한 말, 신조어이면서 줄임말인 말은 종류가 겹칠 수 있습니다. 디저트는 식후 음식이라는 뜻이므로 문맥에 따라 후식 등으로 바꿀 수 있습니다.
아파트 이름 항목에는 실제 이름 6개와 이름 속 표현 6개를 넣었습니다. 브랜드 자체의 어원이나 공식 전체 번역을 제시하지 않고, 일부 영어 낱말의 뜻을 바탕으로 학생이 새 이름을 짓는 활동입니다. 예를 들어 ‘리버파크’에서 ‘강가공원마을’ 같은 새 이름을 생각할 수 있으며 이는 학생의 창작 예시입니다.
